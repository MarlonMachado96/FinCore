# 🚀 FinCore

> Plataforma Inteligente de Gestão Financeira, Contábil e Empresarial.

O **FinCore** é um ERP moderno desenvolvido para centralizar a gestão financeira, contábil e administrativa de micro e pequenas empresas.

Este projeto está sendo desenvolvido com foco em aprendizado, boas práticas de Engenharia de Software e construção de um portfólio profissional utilizando Java, Spring Boot, React e PostgreSQL.

---

# 🎯 Objetivo

Construir um ERP completo que simule um sistema utilizado por empresas reais, contendo módulos financeiros, contábeis, administrativos e de inteligência artificial.

O desenvolvimento será realizado por etapas, priorizando qualidade, organização e escalabilidade.
